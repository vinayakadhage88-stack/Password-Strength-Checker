# 🔐 Password Strength Checker

A simple tool to check whether a password is **strong, medium, or weak** based on common security rules like length, uppercase/lowercase letters, numbers, and special characters.

---

## 📌 Description

This project helps users evaluate the strength of their passwords. It analyzes the given password using basic validation techniques and provides feedback to improve security.

---

## ⚙️ Features

* ✅ Checks password strength instantly
* 🔍 Validates:

  * Minimum length
  * Uppercase & lowercase letters
  * Numbers
  * Special characters
* 📊 Classifies passwords as:

  * Weak ❌
  * Medium ⚠️
  * Strong ✅
* 💡 Gives a simple understanding of password security

---

## 🛠️ Technologies Used

* Python
* Regular Expressions (`re` module)

---

## 🚀 Getting Started

### 📋 Prerequisites

* Install Python (version 3.x)

### ▶️ How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/Password-Strength-Checker.git
   ```

2. Navigate to the project folder:

   ```bash
   cd Password-Strength-Checker
   ```

3. Run the script:

   ```bash
   python password_checker.py
   ```
